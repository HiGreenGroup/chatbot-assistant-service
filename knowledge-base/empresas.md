# Información para empresas

## ¿Cómo publico una vacante en EmpleoServicio?
Para publicar una vacante debes registrar una cuenta de empresa, completar el perfil de tu empresa y luego usar la opción de crear oferta de empleo desde tu panel empresarial. Allí defines título, descripción, requisitos, habilidades y demás detalles de la posición, y la vacante queda disponible para que los candidatos la vean y se postulen.

## ¿Qué beneficios tiene EmpleoServicio para empresas?
La plataforma ofrece acceso a candidatos pre-evaluados, publicación rápida de vacantes, búsqueda avanzada de candidatos por habilidades y experiencia, estadísticas en tiempo real sobre el rendimiento de las publicaciones, y soporte personalizado para optimizar los procesos de contratación.

## ¿Cómo veo y gestiono a los candidatos que se postularon?
Desde el panel de control empresarial puedes ver la lista de candidatos que se postularon a cada una de tus vacantes, revisar sus perfiles y CVs, y dar seguimiento al proceso de selección para cada oferta publicada.

## ¿Qué planes existen para empresas?
EmpleoServicio ofrece distintos planes para empresas, desde un plan gratuito hasta planes pagos (por ejemplo, planes básicos para mipymes, planes premium, de reclutador o empresariales personalizados) que desbloquean funcionalidades adicionales como más publicaciones de vacantes o acceso a pruebas psicométricas para candidatos, según el plan contratado.

## ¿Cómo actualizo el perfil o los datos de mi empresa?
Desde tu panel de empresa puedes editar la información del perfil empresarial: descripción, sector, sitio web, ubicación, beneficios y redes sociales, entre otros datos.
